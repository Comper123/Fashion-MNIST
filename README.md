# Классификация Fashion MNIST

Учебный проект по последовательному улучшению нейронной сети для классификации изображений одежды из датасета Fashion MNIST.

В работе сравниваются четыре подхода:

1. Полносвязная нейронная сеть.
2. Свёрточная нейронная сеть.
3. Свёрточная сеть с аугментациями.
4. Свёрточная сеть с аугментациями и остаточной связью (`skip connection`).

## Результаты

| № | Модель | Параметры | Минимальный `val_loss` | Точность на тесте |
|---:|---|---:|---:|---:|
| 1 | Полносвязная сеть | 235 146 | 0.288408 | 88.35% |
| 2 | Свёрточная сеть | 238 730 | **0.222984** | **91.42%** |
| 3 | CNN с аугментациями | 238 730 | 0.251965 | 89.47% |
| 4 | CNN с аугментациями и skip connection | 238 730 | 0.252178 | 89.86% |

Лучшей по минимальному значению `val_loss` стала обычная свёрточная сеть без аугментаций и остаточной связи. Она достигла точности **91.42%** на тестовой выборке.

## Основные выводы

- Свёрточные слои улучшили качество, поскольку учитывают пространственную структуру изображений и выделяют локальные признаки.
- Аугментации уменьшили признаки переобучения, но в выбранной конфигурации не повысили итоговую точность.
- Остаточная связь не дала заметного улучшения. Вероятно, выбранная сеть недостаточно глубокая, чтобы её преимущество проявилось в полной мере.
- Число параметров во всех трёх свёрточных моделях одинаково, поскольку аугментации и операция сложения не содержат обучаемых параметров.

## Содержимое ноутбука

Ноутбук `fashion_mnist_experiments.ipynb` включает:

- загрузку и визуализацию Fashion MNIST;
- фиксированное разбиение на обучающую и валидационную выборки;
- нормализацию изображений;
- обучение четырёх архитектур;
- вывод `summary()` каждой модели;
- графики `loss` и `accuracy` для обучающей и валидационной выборок;
- примеры изображений до и после аугментаций;
- сравнение моделей в итоговой таблице;
- однократную итоговую оценку на тестовой выборке.

## Воспроизводимость

- Seed: `42`
- Размер батча: `128`
- Максимальное число эпох: `30`
- Оптимизатор: Adam
- Learning rate: `0.001`
- Функция потерь: `SparseCategoricalCrossentropy`
- Критерий выбора лучшей эпохи: минимальный `val_loss`
- Early stopping: `patience=5`

Во всех экспериментах используется одно и то же разбиение данных. Случайные аугментации применяются только к обучающей выборке. Валидационная и тестовая выборки оцениваются без аугментаций. Тестовая выборка используется только для итоговой оценки.

## Запуск локально

Требуется Python 3.10 или новее.

1. Клонируйте репозиторий:

   ```bash
   git clone <URL-репозитория>
   cd <имя-репозитория>
   ```

2. Создайте виртуальное окружение:

   ```bash
   python -m venv .venv
   ```

3. Активируйте его в Windows PowerShell:

   ```powershell
   .venv\Scripts\Activate.ps1
   ```

4. Установите зависимости:

   ```bash
   pip install -r requirements.txt
   ```

5. Запустите Jupyter Notebook:

   ```bash
   jupyter notebook fashion_mnist_experiments.ipynb
   ```

Fashion MNIST загружается автоматически при первом запуске ноутбука.

## Запуск в Google Colab

Загрузите `fashion_mnist_experiments.ipynb` в Google Colab и выберите GPU через меню `Среда выполнения → Сменить среду выполнения`. Ноутбук также может работать на CPU, однако обучение свёрточных моделей займёт больше времени.

## Примечание для Windows

TensorFlow 2.11 и новее не использует NVIDIA GPU при нативном запуске в Windows. Для GPU можно использовать Google Colab или WSL2.
